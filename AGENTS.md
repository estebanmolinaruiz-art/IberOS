# Instrucciones permanentes para agentes y automatizaciones de IberOS

## Regla prioritaria: coste adicional 0 €

**Antes de ejecutar cualquier tarea, leer y aplicar [docs/POLITICA_COSTE_CERO.md](docs/POLITICA_COSTE_CERO.md).** Se aplica a todo el repositorio, incluidos Core, investigación lingüística, Dama de Ilici, La Picola, sitio web, CI, copias, difusión, navegación web y herramientas externas.

- **No contratar, pagar, recargar saldo, activar trial con tarjeta, actualizar planes, consumir APIs de pago ni generar facturación**. No aceptar pagos por sustitución de herramientas sin aprobación expresa: el requisito vigente del proyecto es **0 €**.
- Si hay duda sobre el coste real de una operación, no ejecutarla: utilizar alternativa local y gratuita o reportar el bloqueo.
- Preferir pruebas locales en Python/Node y GitHub Actions estándar para repositorio público, sin sobrepasar los límites gratuitos. No crear automatizaciones recurrentes sin garantía de coste cero.
- Respetar la copia independiente: https://estebanmolinaruiz-art.github.io/IberOS-respaldo/
- No alterar métricas científicas ni promocionar hipótesis a CORE por arreglos técnicos.
- En PR, informar explícitamente **Coste adicional: 0 €**; no declarar pruebas superadas sin evidencia.

Las instrucciones anteriores se interpretan como restricciones de proyecto, no como permiso para gastos futuros. El dominio `iberos-ia.com` ya registrado requiere controlar una posible renovación futura; no renovarlo ni contratar hosting automáticamente.
