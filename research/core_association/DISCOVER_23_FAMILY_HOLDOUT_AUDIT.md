# DISCOVER-23 · Control de independencia por familia de procedencia

**16-11-2026. Ejecutado y confirmado en GitHub Actions, run 43958040605 (éxito).**

El objetivo fue refutar el supuesto implícito de DISCOVER-22 de que dos objetos distintos siempre constituyen una validación independiente. Partimos de las 33 unidades de transcripción editorial normalizadas de 7 identificadores físicos; agrupamos los cuatro Orleyl V, VI, VII-A y VII-B en **una única familia de fuga ORLEYL**. Los demás objetos disponibles son Sagunto (IBR-LAP-0005), Caminreal (IBR-MUS-0001) y Casinos (IBR-PLM-0007). Estos se dejan como familias provisionales independientes, pendientes de auditar otras dependencias.

| Indicador | Resultado |
|---|---:|
| Unidades editoriales extraídas | 33 |
| ID de objetos físicos | 7 |
| Familias de procedencia | 4 |
| Unidades exactas repetidas entre objetos | 5 |
| Unidades exactas repetidas **entre familias** | **0** |
| Variantes a distancia editorial uno entre objetos | 2 |
| Variantes a distancia uno **entre familias** | **0** |

Las cinco formas exactas (anerai, bododaseai, iunstir, selkeai, uskeike) y las dos alternancias (bardoneai/barduneai; iunstir/iustir) proceden exclusivamente de la familia Orleyl. La no aparición fuera de Orleyl **NO refuta** su eventual valor lingüístico: la muestra externa es demasiado corta y heterogénea. Sí bloquea la pretensión de validación externa.

No se creó una supuesta prueba semántica ni valor p donde no existían datos suficientes. Las unidades examinadas proceden de **ediciones**, no de reconocimiento gráfico independiente. No hay un nuevo desciframiento.
