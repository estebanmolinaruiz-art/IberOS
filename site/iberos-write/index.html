IberOS-Write

Motor inverso de reconstrucción controlada. Convierte una intención en una propuesta escrita solo cuando existe soporte suficiente; cuando no lo hay, debe abstenerse o usar un fallback fonográfico claramente marcado.

Regla principal

No inventar léxico ni funciones. Una forma visual convincente no sustituye evidencia lingüística.

Fallback permitido

Si no existe reconstrucción ibérica defendible, Write puede representar el castellano fonográficamente con simbología ibérica, siempre identificado como fallback y nunca como traducción.

Trazabilidad obligatoria

Toda imagen debe poder volver a su texto fuente y a la secuencia exacta que la generó.

Capas de salida

CapaUsoRegla pública
ValidadoLectura, segmentación o función respaldada por IberOSPuede mostrarse sin convertirla en traducción literal si esa literalidad no está demostrada.

FallbackCastellano representado fonográficamenteDebe distinguirse visualmente y declararse como no ibérico semántico.
HuecoFalta de coberturaWrite se abstiene antes que inventar.

Pipeline obligatorio

texto original → marco semántico → evidencia disponible → reconstrucción / abstención / fallback → secuencia exacta → render → WRITE_ID + registro trazable
Regla de render: nunca generar primero una imagen y reconstruir después qué debía decir. La cadena fuente y la secuencia escrita se congelan antes del render.
Regla de reversibilidad: cada salida visual científica debe incluir WRITE_ID, texto original, versión del motor, secuencia exacta, estado de cada segmento y hash de integridad.
Regla verbal: Write no seleccionará DE frente a DI, ni resolverá otros contrastes abiertos, sin evidencia independiente suficiente.

Métricas visibles

SEMANTIC-COVERAGE

Qué parte del contenido solicitado está realmente cubierta por elementos lingüísticos defendibles.

FALLBACK-RATE

Qué proporción depende de transliteración/préstamo moderno en lugar de reconstrucción ibérica.

Imágenes y pruebas históricas

Una imagen sintética con signos de apariencia ibérica que no conserve su cadena fuente se clasifica como visual ilustrativo no verificable. No entra en PALEO, corpus, benchmark ni validación.

Estado

BLIND Reconstruction Test: activo. IberOS-Write consume el núcleo IberOS de forma unidireccional y no puede modificarlo automáticamente.
