IberOS Open Research Kit

IberOS — created by Esteban Molina Ruiz

Independent, reproducible tooling and machine-readable research outputs for internal analysis of Iberian inscriptions.

Use it

pip install iberos (after PyPI publication)

iberos show-object IBR-PLM-0002

Interoperate

Consume IberOS JSON records through the public JSON Schema. Other programs do not need to use the IberOS engine to read IberOS outputs.
