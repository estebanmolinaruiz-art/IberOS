Guía de uso

Cómo funciona IberOS

IberOS es un entorno experimental y reproducible para analizar inscripciones ibéricas combinando documentación arqueológica, lecturas epigráficas publicadas y procedimientos computacionales.

1. Instalar

La versión pública puede instalarse desde PyPI:

python -m pip install iberos==1.0.1
iberos --help

Repositorio: GitHub ↗

2. Seleccionar una inscripción

El análisis parte de una pieza o entrada documentada del corpus. Cada caso debe conservar su procedencia, objeto físico, edición publicada y dependencia documental.

Abrir corpus → · Abrir fichas →

3. Separar niveles de conocimiento

IberOS obliga a mantener separadas las capas:

EVIDENCE → INFERENCE → HYPOTHESIS → ESTIMATED TRANSLATION

Una lectura documentada no se convierte automáticamente en significado. Una recurrencia estructural tampoco se trata como traducción demostrada.

4. Controlar la independencia de los datos

Las entradas se relacionan mediante identificadores de objeto físico y grupos de dependencia para evitar contar varias ediciones o copias del mismo testimonio como evidencias independientes.

ENTRY → PHYS_ID / OBJECT_ID → LEAK_GROUP → TRAIN / VAL / HOLD

5. Ejecutar análisis reproducibles

El software permite trabajar con patrones, segmentación, recurrencias, comparación estructural y validaciones controladas. Los experimentos sintéticos validan el software, no el desciframiento de la lengua.

Abrir laboratorio → · Ver reproducibilidad →

6. Interpretar resultados con límites explícitos

IberOS registra resultados positivos, negativos e inconclusos. Las hipótesis semánticas permanecen abiertas mientras no exista evidencia externa suficiente.

El proyecto no afirma haber descifrado la lengua ibérica ni presenta porcentajes internos como porcentaje de lengua descifrada.
