# IberOS Curated Benchmark v1.0

Creator: **Esteban Molina Ruiz**

This dataset repository contains **IberOS-original curation and interoperability metadata** for 38 curated objects, plus provenance references and a partial mapping to public upstream identifiers.

It does not claim ownership of underlying inscription texts, images or third-party editions.

## Main files

- `curated/iberos_objects_registry_v2.0.csv`
- `curated/iberos_family_links_v2.0.csv`
- `curated/iberos_partial_entry_link_v2.4.csv`
- `curated/iberos_curated_objects_v1.jsonl`
- `examples/*.json`

## Intended use

Interoperability, benchmarking, provenance checks and comparison with other research software.
