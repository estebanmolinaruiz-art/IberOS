## Texto para foro de especialistas

**Título:** IberOS: corpus consultable y procedimientos reproducibles para investigar inscripciones ibéricas

Comparto IberOS, un proyecto independiente de investigación abierto a revisión crítica. Permite explorar documentación epigráfica y contrastar hipótesis de segmentación y morfología, con distinción explícita entre lectura física, inferencia y semántica experimental. No presenta una traducción definitiva del ibérico. Nos interesan especialmente comentarios sobre trazabilidad de fuentes, lecturas paleográficas y criterios de falsación.

### Presentación para desarrolladores (ES)

**IberOS: software abierto para investigación reproducible de epigrafía ibérica**

IberOS explora cómo combinar herramientas digitales, documentación de inscripciones ibéricas y controles de validación reproducible. Invitamos a desarrolladores a revisar el código, la experiencia de usuario, las pruebas, la trazabilidad de datos y posibles mejoras de accesibilidad. ### Developer introduction (EN)

**IberOS: open software for reproducible Iberian epigraphy research**

IberOS brings together tools for exploring ancient Iberian inscriptions and reproducible hypothesis testing. Developers interested in open-source software, digital humanities, search UX, accessibility, data provenance, testing, or computer vision are welcome to review the code and propose improvements. Linguistic interpretations remain provisional; IberOS does not claim to have deciphered Iberian.
