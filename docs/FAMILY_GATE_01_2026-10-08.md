# FAMILY-GATE-01 — 2026-10-08

The IberOS core now connects the PHYS/LEAK-SAFE evidence engine to six active scientific families:

- SALIR
- ŔOK
- KA/KE/KU
- KUTUR
- BAIDES/BATIR
- NUM-METRO

Each family has two separate gates:

1. **functional** — tests the broad functional/structural domain currently allowed by the frozen release;
2. **exact** — tests narrower literal, directional or lexical claims.

All gates:
- de-duplicate evidence by PHYS_ID / LEAK_GROUP;
- require explicit evidence classes;
- can require orthogonal evidence;
- may require a named prospective gate;
- return REVIEW_ELIGIBLE, OPEN or BLOCKED;
- never promote CORE automatically.

Narrow literalizations remain protected. Examples:
- SALIR is not automatically money/silver/payment/price;
- ŔOK does not fix give/deliver/receive or participant direction;
- KA/KE/KU does not fix source/target/provider/receiver;
- KUTUR is not universally ritual/money/commodity/gift/unit;
- BAIDES/BATIR exact office remains open;
- exact numeral values are evaluated lexeme by lexeme.

Scientific authority remains C594 / C474 / C539 / C541.
