# IberOS — Kit de difusión gratuita

**Estado:** materiales de comunicación; no modifican CORE, hipótesis, métricas ni releases científicas.

## Presentación breve (ES)

IberOS es un proyecto independiente y abierto de investigación sobre inscripciones ibéricas. Ofrece herramientas para explorar documentación epigráfica y contrastar hipótesis mediante criterios reproducibles, con distinción entre evidencia, inferencia e interpretación provisional. No afirma haber descifrado la lengua ibérica.

## Short description (EN)

IberOS is an independent, open research project for reproducible analysis of ancient Iberian inscriptions. It provides exploratory tools, provenance-aware records, and falsifiable validation workflows, explicitly distinguishing evidence, inference, and provisional interpretation. It does **not** claim to have deciphered the Iberian language.
